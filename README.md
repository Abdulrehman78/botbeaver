# BotBeaver

Marketing site for BotBeaver LLC — AI lead capture and client communication for US teams.

## Pages

- `/` — home
- `/services` — AI Sales Development Representative, outbound layer, AI Phone Receptionist
- `/process` — how engagements work
- `/pricing` — scoped pricing approach
- `/faq` — buyer questions
- `/contact` — book a demo
- `/legal/*` — privacy, terms, cookies, refund, acceptable use, DPA, data deletion

## Run

```bash
npm install
npm run dev
```

## Notes

- Contact form is marketing-only until a CRM/email backend is connected.
- Legal pages are drafts for counsel review.
- Package name: `botbeaver-site`.
